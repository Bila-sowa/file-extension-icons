<h1>About</h1>

<p>This repository is required for the <a href="https://github.com/Bila-sowa/GitMap">GitMap</a> repository to work. It contains more than 1000 icons for file extensions. Icons collected from a popular extension <a href="https://github.com/material-extensions/vscode-material-icon-theme">Material Icon Theme</a>.</p>

<h2>Characteristic</h2>

* Color: white
* Size: 24x24 px
* Type: svg

## Usage

``` HTML
<img src="https://raw.githubusercontent.com/Bila-sowa/file-extension-icons/main/icons/(file.extension).svg"></img>
```
